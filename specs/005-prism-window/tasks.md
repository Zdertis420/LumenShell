# Tasks: Prism Window (Skeleton)

**Input**: Design documents from `/specs/005-prism-window/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/, quickstart.md. Features I to IV (`specs/001-foundation/` to `specs/004-bar-customization-styles/`) are implemented. Module interface 1.2 is in place.

**Tests**: Included, as in Features III and IV. The constitution requires automated tests for logic and a check for each customization setting and each keyboard rule, so the pure QML functions get `qmltestrunner` tests, the settings and the limit get Go tests, the static scans are extended, and the rest is exercised in the quickstart and the smoke script on a real Quickshell on niri.

**Organization**: Grouped by user story. The shared pieces every story needs (interface 1.3, the 105 settings, the pure functions, the module shell) are in Phase 2. `PrismWindow.qml` and `Main.qml` are touched by several stories, so those tasks are in order and not marked [P].

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependencies on unfinished tasks)
- **[Story]**: Which user story the task belongs to (US1 to US6)

## Path Conventions

Paths are relative to the repository root (see plan.md "Source Code"). The module is `modules/prism/`; tests are in `scripts/tests/`; the contracts are in `specs/005-prism-window/contracts/`. Go programs stay standalone under `scripts/src/<name>/`. Every file must pass `make fmt`, `make lint` and `make test`.

## Implementation Strategy

### MVP first (User Story 1)

1. Phase 1 (at least T001 and T002) and Phase 2.
2. Phase 3 (US1): open, type, close, keyboard back.
3. Stop and check it by hand: Prism is a working, empty, keyboard-driven window.

### Incremental delivery

1. Foundation and US1: the window opens and closes.
2. US2 and US3 (both P1): placement and theming, the heart of the request.
3. US4: the preview rows, so the look can be judged.
4. US5: the source slot, so later features can fill the window.
5. US6 and Polish: degradation, docs, the full run.
